    الاتصال والبروكسي

    اختر نطاق الاتصال. عند تفعيل نطاق التطبيق، تمر طلبات الموديل عبر البروكسي أيضًا. فشل البروكسي يوقف الاتصال.

    HTTP · HTTPS · SOCKS5 · SOCKS4a، مع مصادقة حسب النوع.

    اختبار IP يفحص المتصفح فقط. لا يشمل نظام التشغيل أو برامجك الأخرى. يتوقف الاتصال عند فشل البروكسي.

    الكتابة في المتصفح

    استلم التحكم، ثم انقر الحقل في الصورة. النص يُرسل للمتصفح فقط.
